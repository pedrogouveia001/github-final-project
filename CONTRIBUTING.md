# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for your interest in contributing to the Simple Interest Calculator.

## How to contribute

1. Fork this repository.
2. Create a descriptive branch for your changes.
3. Make focused changes and test the script.
4. Commit your changes with a clear message.
5. Open a pull request explaining what you changed and why.

## Testing

Run `bash simple-interest.sh` and test with positive numerical values. For example, principal 1000, interest rate 5, and time 2 should result in simple interest 100.

## Issues

Before opening a new issue, check whether the same problem or suggestion has already been reported. Include steps to reproduce any bug.
