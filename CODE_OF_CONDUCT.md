# Code of Conduct

## Our commitment

We aim to maintain a welcoming, respectful, inclusive environment for everyone participating in this project.

## Expected behavior

- Be respectful and considerate of different experiences and perspectives.
- Give constructive feedback and accept feedback gracefully.
- Focus on collaboration and the improvement of the project.

## Unacceptable behavior

Harassment, discrimination, insults, intimidation, or sharing others' private information without permission are not acceptable.

## Reporting and enforcement

Report problematic behavior privately to the repository maintainer through an appropriate GitHub contact channel. The maintainer may remove harmful content or restrict participation as needed.

This code of conduct applies to project discussions, issues, pull requests, and other project-related interactions.
